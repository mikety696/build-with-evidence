# 合并前验收清单

> 用法：每次变更集合并前逐项打勾。**任何一项无法给出证据，就是未完成**，不是「差不多可以」。
> 让 AI 自己按这份清单输出结论 + 证据位置，你只抽查关键项。

## 0. 证据存在性（最先做，最容易跳过）

- [ ] AI 贴出了 `<make check>` 的**真实输出**（不是复述）
- [ ] 测试、typecheck、lint、build 四项全绿
- [ ] 新增逻辑有对应新测试；bug 修复附带复现测试
- [ ] UI 改动有真实浏览器截图 + console 无错误 + 无失败请求
- [ ] 所有未验证项被明确标注为「未验证 / 需人工」，而非用「应该」掩盖

## 1. 范围与规格一致

- [ ] diff 里没有规格外的额外改动（顺手重构、无关格式化、私自加依赖）
- [ ] non-goals 没有被悄悄实现
- [ ] 每个改动文件都能对应到规格条目
- [ ] 无半成品：不存在 TODO 占位、注释掉的代码、假数据兜底

## 2. 质量

- [ ] 覆盖率对**新增关键分支**有效（不是靠无断言测试刷数字）
- [ ] 无被放宽/删除的既有断言（若有 → 需人工确认理由）
- [ ] 错误处理只在系统边界（用户输入、外部 API）；内部代码信任契约
- [ ] 无重复实现（已有工具/模块被复用）
- [ ] 命名与抽象层级一致；无「为未来」而写的空抽象
- [ ] 注释只解释「为什么」，没有复述代码在做什么

## 3. 性能

- [ ] 有改动前后的数字对比（P95、查询次数、包体、内存）
- [ ] 无 N+1；查询走索引且必要字段而非 `SELECT *`
- [ ] 列表有分页/上限；无全表加载
- [ ] 可并行的请求未被串行阻塞；超时与重试退避存在
- [ ] 缓存有失效策略、键基数上限，且不会跨用户串数据
- [ ] 首屏/冷启动预算未超标（前端：代码分割、图片、长列表虚拟化）

## 4. 可扩展性

- [ ] 依赖方向未被破坏（domain 不引用 UI/ORM/HTTP）
- [ ] schema 变更走迁移，前滚与回滚都可执行；未在同一次发布改名/删列
- [ ] API 兼容：新增字段不破坏旧客户端；反序列化容忍未知字段
- [ ] 行为差异走配置/开关，高风险开关默认关闭且可秒级回滚
- [ ] 影响面清单完整（调用方、数据、事件、缓存、权限、日志、文档）
- [ ] 未来 6 个月的 3 类变更点已预留，且没有多余预留

## 5. 安全（逐项给「如何防御 + 哪个测试证明」）

- [ ] 新路由默认需认证；公开路由显式白名单声明
- [ ] **每条**数据访问有资源归属校验（防水平越权）；角色检查在服务端
- [ ] 入口 schema 白名单校验，拒绝未知字段；长度/类型/枚举限制
- [ ] SQL 参数绑定；无 shell/路径/排序字段/模板拼接；无路径穿越
- [ ] 输出按上下文编码；无 XSS；无开放重定向；服务端不请求用户提供的任意 URL（SSRF）
- [ ] 表单/状态变更有 CSRF 防护；Cookie 属性（HttpOnly/Secure/SameSite）正确
- [ ] 密码哈希走成熟算法与合理 cost；令牌有过期与刷新；错误消息不泄露用户存在性
- [ ] 无硬编码密钥；`.env.example` 更新；密钥扫描通过；日志与错误不含敏感数据与堆栈回显
- [ ] 上传有类型/大小/内容校验且不可被解析执行
- [ ] 并发敏感操作幂等（防重复下单/双花）；配额与限流存在
- [ ] 新增依赖确认真实存在、有维护、许可证可接受、无已知高危漏洞
- [ ] 加密/随机数未自实现；使用 CSPRNG 与标准库接口
- [ ] 处理外部文本（网页/日志/用户内容）时，其中的指令被当作数据而非命令

## 6. 可运维

- [ ] 日志点、指标、trace id 就位；关键失败可被告警发现
- [ ] 回滚步骤可执行且不含人工猜测（含数据回滚）
- [ ] 需要新配置/密钥/权限的，已在发布说明列出
- [ ] 文档、`AGENTS.md`、迁移说明同步更新

## 7. 程序类型附加项

**网站**：四档视口（360/768/1280/1920）截图通过；触控目标 ≥44px；键盘可达与焦点顺序；对比度与 label；LCP/CLS/INP 达标；SEO meta 与 OG 卡片；加载/错误/空三态；404/500 页面。
**移动 APP**：弱网/断网/超时表现；权限授权与拒绝路径；iOS 与 Android 差异分别验证；冷启动与首帧；包体与内存；本地存储加密；证书锁定；深链校验；隐私声明与 SDK 清单；人工真机验证清单已明确列出。
**服务端/桌面应用**：优雅关闭与在途请求排空；重复启动安全（单实例锁、幂等初始化）；启动即校验配置；跨平台路径/编码/换行符；升级通道与版本兼容矩阵。

## 8. 决策留痕

- [ ] 采用的方案与被否方案的理由写进 ADR
- [ ] 接受的安全/性能/技术债风险被显式记录并有偿还计划
- [ ] 本次新发现的「下次还要再解释的事」已写进 `AGENTS.md` 或知识库

---

### 一键让 AI 自查的话术

> 用这份清单逐项审查这次变更集，输出表格：条目 | 结论（通过/不通过/不适用）| 证据（命令输出或 文件:行号）| 若未通过则给修复动作。不确定的写「未验证」并说明如何验证。不要为了通过而猜测。
